# 📌 Project Overview

This project started as a **small Crop Recommendation Machine Learning project**.

The initial version focused mainly on predicting a suitable crop using agricultural parameters such as:

* 🌿 Nitrogen
* 🧪 Phosphorus
* 🧪 Potassium
* 🌡️ Temperature
* 💧 Humidity
* 🧬 Soil pH
* 🌧️ Rainfall

The project is now being **rebuilt from the ground up** and expanded into a much larger:

> 🌾 **AI-Powered Agricultural Intelligence Platform**

The new version will gradually combine **Data Analytics, Machine Learning, Deep Learning, Computer Vision, Weather Intelligence and Recommendation Systems**.
